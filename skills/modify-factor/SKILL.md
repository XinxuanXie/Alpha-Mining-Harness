# 修改因子

一轮修改至多用五种方法，每种方法只产出一条新因子，全部回测后挑最好的一条交付。一轮测完即止，不接着改下一轮；下一步只写进结论，不在本轮执行。

输入：原因子（名称、假设、公式）及其成绩单。没有成绩单的，先回测再修改。

## 第一步：诊断

成绩单的读法已在生成因子的 skill 里写过，这里不重复。本步只做一件事：从成绩单里确认这次要治的那一个问题——写明是哪项指标、什么形态（如"ICIR 低而 IC 尚可""信号只活在 1–5 日"）。诊断决定下一步选哪些方法，不先定方法再找理由。诊断只依据成绩单，不另写脚本计算其他统计量。

## 第二步：选方法

从下表选至多五种，与诊断对症。每种方法写明治什么、怎么改、注意什么。

| 方法 | 治什么 | 怎么改 | 注意 |
|---|---|---|---|
| 正交化 orthogonalization | 怀疑因子只是某个已知量的影子 | 对可疑量做截面回归取残差：`resid(因子, 可疑量)` | 这是审判不是增益：先确认它到底测到了什么 |
| 收益分解 return decomposition | 分不清信号来自隔夜还是日内、来自收益的哪一段 | 把收益拆段后只取其中一段重构因子（如只取隔夜段） | 同为审判型，优先于增益型 |
| 波动率缩放 volatility scaling | IC 尚可但 ICIR 低，信号被高波动股票主导 | 因子除以个股波动：`因子 / ivol20` 或用残差收益重构 | 缩放改变的是权重，不是信号本身 |
| 中性化 neutralization | 暴露集中在规模或行业，怀疑是壳效应 | 对规模取残差 `resid(因子, log(mktcap))`，或改用行业内排名 `rank_sector` | 中性化后归零说明原信号就是壳，结案而非继续改 |
| 残差收益构造 residual return construction | 信号混在市场共同波动里 | 把价格收益换成残差收益 `resid_ret` 重构因子 | 适用于收益类因子 |
| 指数衰减加权 exponential decay weighting | 信号有时效性，旧信息应降权 | 把 `ts_mean` 换成 `ts_decay`，或对因子做衰减平滑 | 半衰期要有依据，不要逐个试 |
| 缩尾处理 winsorization | 极端值主导截面排序 | 对因子或中间量套 `winsorize` | 只治分布尾巴，不改变信号方向 |
| 状态条件化 regime conditioning | 信号只在某种市场状态下成立 | 用 `where` 按状态切换信号的开与关或取不同构造 | 状态须由假设先行给出，不得看完成绩单再挑状态 |
| 间隔期构造 skip-period construction | 最近一段混有微观结构噪声（反转类常见） | 跳过最近 1–5 日再取窗口，如把起点改为 delay 后的区间 | 主要用于反转与动量 |
| 时序标准化 time-series standardization | 量的尺度随时间漂移，截面不可比 | 按自身历史标准化，如除以过去一段的 `ts_std` 或用 `ts_rank` | 窗口要覆盖足够历史 |
| 构造迁移 construction transfer | 原因子构造方式单一 | 参考其他家族因子的变量构造与函数形式，重新构造原因子信号 | 迁移的是构造方法而非信号本身；异质信号直接合成，样本外表现差 |

## 第三步：改公式并回测

每种方法改出一条新公式：每条只用一种方法，不叠加第二种；方法本身需要重构公式的，按方法来。逐条运行 IS 段回测：

```
python tools/backtest/backtest_is.py "<新公式>"
```

成绩单会打印出来，并自动存一份 JSON 到 `results/` 目录。原因子的成绩单在 `results/` 里定位：用原因子的完整公式在各 JSON 的公式字段中精确检索，不要用公式片段（会命中多份）。定位到后直接取用，不许补跑；只有确实找不到记录时，才对原因子补跑一次回测取数。

全部测完后，挑出最好的一条（以 20 日 IC、ICIR 为主），为它生成报告：

```
python report.py "<挑中的公式>" --segment is
```

## 第四步：对比与交付

交付前逐项核对：文字里对新旧成绩的每一句描述（哪项升了、哪项降了、是否单调），都要与数字对得上，先看数字再下笔。

交付以下内容：

- 诊断（一句话，问题在哪）；
- 本轮试过的全部方法逐条列出（方法、改法、各自的 20 日 IC 与 ICIR），标明挑中哪一条，不许只报最好的一条；
- 挑中条的改法：原因子 → 新因子，改了什么；
- 新旧对比：挑中条与原因子的 IC、ICIR 及与诊断相关的那几项，前后变化；
- 报告路径；
- 结论：新因子保留、还是弃用回到原因子，给出理由；下一步建议只写不做。

交付时只写改法本身，不点名所参考的经典库条目编号或名称。

## 第五步：记研究记忆

把本轮挑中的一条追加到 `alpha_research_memory.md`，写一张卡，三项：

- 假设由来：写清原假设是什么、本轮改成了什么，使没参与本轮的人只看这一张卡就能看懂；
- 因子公式：挑中条的完整公式；
- 经验：结合本轮结果提炼一条下一轮能直接用的认识；结果本身与具体数字不写进来。

落选的改法不记。卡的写法以 `alpha_research_memory.md` 文件开头的说明为准。
