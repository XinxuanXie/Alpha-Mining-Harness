# 生成因子

接到生成因子的任务后，按下面五步走完，不要停在公式交付。一次生成一条。

## 第一步：读资料

- 读 `classic_library.md` 索引，从 13 个家族里选 2–3 个读其条目原文（文件在 `classic_library/` 下）。选法：与当前想探索的方向相关，或随机抽取，避免每次都翻同一批。
- 确认算子与字段清单：以 `engine.py` 中的字段集与算子集为准，公式只能用清单内的字段与算子。
- 确认数据口径：字段含义与数据说明见主说明书的环境一节；特别注意价格为拆股调整后价格。

产出：几个可借鉴的测量方式（条目背后的量法），以及可用字段、算子的边界。

## 第二步：提出假设

用一句话写下假设：要量的是什么、为什么它可能预测未来收益。

- 假设必须能被现有数据量到：量不到的东西不写进假设。
- 假设里说清所量的东西与收益之间预期的方向（正还是负）。

## 第三步：写公式

按假设写一条公式，把假设要量的东西落成计算。

- 只用第一步确认过的字段与算子；公式只使用当日及以前的数据。
- 一条公式量一件事，结构以一句话能说清为准。
- 写完对照假设自查：公式实际量到的与假设要量的是不是同一个东西，方向是否一致。

## 第四步：回测

运行训练段回测，等待成绩单输出：

```
python backtest_train.py "<公式>"
```

成绩单会打印出来，并自动存一份 JSON 到 `results/` 目录（文件名含数据段与时间，内容为公式与 15 项数字），后续查阅、对比从那里取。

需要看图时再生成报告：

```
python report.py "<公式>" --segment train
```

公式报错时按报错信息修正公式（清单外算子、表达式结构不支持等），不要绕过。

## 第五步：看成绩单，给建议

对照成绩单写一段建议，包含三点：

- **离参考线多远**：判定参考线为 20 日 IC ≥ 0.02、ICIR ≥ 0.2，看 IC、ICIR 与它的差距。
- **主要问题是什么**：结合持有期 IC 的形态（信号集中在哪几天）、五组收益是否单调、多空价差与胜率，指出最突出的一两个问题。
- **下一步建议**：继续修改（往哪个方向改）、换一个假设、还是就此结案，三选一并给出理由。

最终交付：名称、假设、公式、成绩单要点、建议。
