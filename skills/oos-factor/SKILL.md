# OOS 段验证

OOS 段只做裁决，不做挑选：同一条公式在 OOS 段只跑一次，跑完不许拿 OOS 段结果回去改因子再测。没有用户明确指令，不启动本流程。

输入：因子（名称、假设、公式）及其 IS 段成绩单。IS 段成绩单在 `results/` 里定位：用因子的完整公式在各 JSON 的公式字段中精确检索（is_*.json）；确实找不到记录时，先补跑一次 IS 段回测取数。

## 第一步：OOS 段回测与报告

```
python backtest_oos.py "<公式>"
python report.py "<公式>" --segment oos
```

OOS 段成绩单自动存一份 JSON 到 `results/`（oos_*.json），报告与它同名、同存 `results/`。

## 第二步：对比与交付

交付前逐项核对：文字里对两段成绩的每一句描述，都要与数字对得上，先看数字再下笔。

交付以下内容：

- 因子名称、假设与公式；
- IS 段与 OOS 段并排对比：20 日 IC、ICIR、t 值、五组收益、分组单调性、多空价差，以及各持有期 IC 的形态变化；
- OOS 段报告路径；
- 结论：OOS 段上是存活、衰减还是反转，给出依据；下一步建议只写不做（结案、回 IS 段继续修改、或申请 holdout 段——holdout 段须另行明确指令）。
