# 四、波动与风险

波动、偏度、贝塔等风险特征与收益的关系，主体为低风险占优。构造以滚动波动、回归贝塔、残差统计与 OHLC 波动估计量为主。

- **C08 低波动**：`neg(ts_std(close / delay(close, 1) - 1, 60))`，经济意义：杠杆约束与彩票偏好使高波动股票被高估，低波动股票跑赢。
- **C09 彩票 MAX**：`neg(ts_max(close / delay(close, 1) - 1, 20))`，近月单日最大涨幅取负，经济意义：彩票偏好使近月出现极端涨幅的股票被高估，其后收益偏低。
- **C10 低贝塔**：`neg(ts_corr(close / delay(close, 1) - 1, mktret, 252) * ts_std(close / delay(close, 1) - 1, 252) / ts_std(mktret, 252))`，252 日贝塔取负，经济意义：杠杆约束使高贝塔股票被高估，低贝塔股票风险调整收益更高。
- **C38 市场贝塔·5 年**：`ts_beta(close / delay(close, 1) - 1, mktret, 1260)`，窗口 5 年，与 C10 的区别在窗口，经济意义：贝塔度量系统性风险，预期收益随贝塔上升，作为承担不可分散风险的补偿。
- **C39 FP 贝塔**：以三日重叠收益计算的相关×波动比，`ts_corr(close / delay(close, 3) - 1, 市场三日收益, 1260) * ts_std(close / delay(close, 3) - 1, 1260) / ts_std(市场三日收益, 1260)`，市场三日收益为程序自算量，经济意义：杠杆受限的投资者超配高贝塔资产使其高估，低贝塔资产风险调整收益更高。
- **C40 尾部风险贝塔**：`ts_beta(returns, 尾部冲击序列, 252)`，尾部冲击序列为每日截面收益 5% 分位以下股票的平均收益（程序自算），经济意义：对尾部冲击暴露高的股票在极端行情中损失更大，投资者要求尾部风险溢价。
- **C41 特质波动·1 年 CAPM**：`neg(过去 1 年日收益对市场收益回归的残差标准差)`，残差序列为程序预计算量，经济意义：卖空约束使高特质波动股票被高估，低特质波动股票其后跑赢。
- **C42 已实现波动·1 月**：`neg(ts_std(close / delay(close, 1) - 1, 21))`，与 C08 的区别在窗口与总波动口径，经济意义：高波动股票受彩票偏好追捧而被高估，低波动股票其后收益更高。
- **C43 协偏度·月频**：`ts_mean((r - ts_mean(r, 60)) * power(mktret - ts_mean(mktret, 60), 2), 60) / (ts_std(r, 60) * power(ts_std(mktret, 60), 2))`，月频口径、窗口 60 个月，r 为个股月收益（程序自算），经济意义：投资者偏好正偏态收益，与市场收益负协偏的股票须以更高预期收益作补偿。
- **C44 协偏度·日频**：`ts_mean((r - ts_mean(r, 252)) * power(mktret - ts_mean(mktret, 252), 2), 252) / (ts_std(r, 252) * power(ts_std(mktret, 252), 2))`，日频口径、窗口 1 年，r 为个股日收益（程序自算），经济意义：市场下跌时跌幅更大的股票承担下行风险，投资者要求下行风险溢价补偿。
- **C45 收益偏度**：`neg(ts_skew(close / delay(close, 1) - 1, 21))`，近月日收益偏度取负，经济意义：高正偏度股票具彩票特征而被投资者高估，其后收益偏低。
- **C46 特质偏度·CAPM**：`neg(过去 1 个月 CAPM 残差的偏度)`，残差序列为程序预计算量，经济意义：特质正偏度反映个股彩票属性，被高估后其后收益偏低。
- **C93 WQ#34 波动比×日跌**：`rank((1 - rank(ts_std(returns, 2) / ts_std(returns, 5))) + (1 - rank(delta(close, 1))))`，经济意义：短期波动收敛叠加价格回落，反映恐慌释放后的短期反转修复。
- **C146 价格离散 STD**：`ts_std(close, 20) / close`，价格标准差按现价归一，经济意义：以价格离散度量短期波动风险，波动越高定价不确定性与风险暴露越大。
- **C169 量加权波动比 WVMA**：`ts_std(abs(returns) * volume, 20) / ts_mean(abs(returns) * volume, 20)`，量加权涨跌幅的变异系数，经济意义：量加权涨跌幅的离散度量放量波动的稳定性，离散越大交易拥挤与冲击风险越高。
- **C179 平均真实波幅比 ATR**：`ts_mean(max(high - low, abs(high - delay(close, 1)), abs(low - delay(close, 1))), 14) / close`，经济意义：度量日内真实波动幅度，波幅越大风险越高，投资者要求更高收益补偿。
- **C193 Parkinson 波动**：`sqrt(ts_mean(power(log(high / low), 2), 20) / (4 * log(2)))`，仅用日内高低极值估计波动，经济意义：以日内高低极值度量波动风险，波动越高投资者要求的风险补偿越高。
- **C194 Garman-Klass 波动**：`sqrt(ts_mean(0.5 * power(log(high / low), 2) - (2 * log(2) - 1) * power(log(close / open), 2), 20))`，高低极值与开收结合，经济意义：结合极值与开收信息度量波动风险，波动越高风险补偿要求越高。
- **C195 Rogers-Satchell 波动**：`sqrt(ts_mean(log(high / close) * log(high / open) + log(low / close) * log(low / open), 20))`，允许漂移的极值估计，经济意义：在价格漂移下度量波动风险，刻画趋势行情中的波动暴露与补偿。
- **C196 Yang-Zhang 波动**：`sqrt(σ²_隔夜 + k * σ²_开收 + (1 - k) * σ²_RS)`，σ²_RS 为 Rogers-Satchell 方差（C195 同口径）、k = 0.34 / (1.34 + (n + 1) / (n - 1))、n = 20（程序自算），经济意义：综合隔夜跳跃与日内波动度量总风险，波动越高风险补偿越高。
- **C197 Roll 隐含价差**：`2 * sqrt(max(-ts_cov(returns, delay(returns, 1), 60), 0))`，由收益负自协方差反推有效价差（程序自算），经济意义：隐含价差度量交易成本，价差越大流动性越差，投资者要求流动性溢价补偿。
- **C198 下行半方差占比**：`ts_sum(power(min(returns, 0), 2), 20) / ts_sum(power(returns, 2), 20)`，下行波动占总波动之比（程序自算），经济意义：下行半方差占比度量左尾风险，投资者对下行风险要求补偿。
- **C199 跳跃方差占比**：`(已实现方差 - 双幂变差) / 已实现方差`，20 日口径（双幂变差为程序自算），经济意义：度量跳跃风险占总波动的比重，跳跃暴露越高要求跳跃风险溢价越高。
- **C200 隔夜方差占比**：`ts_sum(power(open / delay(close, 1) - 1, 2), 20) / ts_sum(power(close / delay(close, 1) - 1, 2), 20)`，隔夜波动占全日波动之比（程序自算），经济意义：度量隔夜信息冲击占总波动的比重，隔夜风险暴露越高要求补偿越高。
