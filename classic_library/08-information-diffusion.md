# 八、信息扩散与行业领先滞后

信息在个股间扩散的速度差异。构造以价格延迟回归、滞后相关与行业内大市值股票的领先收益为主。

- **C60 价格延迟·R²版**：`1 - R²(受限模型) / R²(完整模型)`，完整模型为个股收益对市场收益当期及滞后 1–4 期回归、受限模型只含当期项（程序预计算），经济意义：价格对市场信息的反应延迟源于信息摩擦与投资者认知不足，延迟高者要求风险补偿。
- **C61 价格延迟·系数版**：`(1*|β1| + 2*|β2| + 3*|β3| + 4*|β4|) / (|β0| + |β1| + |β2| + |β3| + |β4|)`，β 为 C60 完整模型各期系数（程序预计算），经济意义：价格对市场信息的反应延迟源于信息摩擦与投资者认知不足，延迟高者要求风险补偿。
- **C62 价格延迟·显著性版**：`(1*|t1| + 2*|t2| + 3*|t3| + 4*|t4|) / (|t0| + |t1| + |t2| + |t3| + |t4|)`，t 为 C60 完整模型各期系数的 t 值（程序预计算），经济意义：价格对市场信息的反应延迟源于信息摩擦与投资者认知不足，延迟高者要求风险补偿。
- **C63 行业大票收益**：`赋给行业内其余股票的同业市值前 30% 股票上期平均收益 = sector_big_mean(delay(returns, 1))`（程序自算），经济意义：行业信息先反映在大市值股票价格中，再经渐进信息扩散传导至同行业小股票。
- **C95 WQ#37 隔夜日内相关＋日内**：`rank(ts_corr(delay(open - close, 1), close, 200)) + rank(open - close)`，经济意义：日内涨跌与价格水平的时序关联，度量日内价格压力的持续性。
