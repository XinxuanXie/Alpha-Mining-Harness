# 五、流动性与换手

交易活跃度与非流动性溢价。构造以成交量均线比、换手率、Amihud 比率、零成交天数与量能累积指标为主。

- **C06 放量**：`ts_mean(volume, 5) / ts_mean(volume, 60)`，短长均量比，经济意义：短长均量比度量交易活跃度骤升，放量反映关注度与情绪交易需求激增。
- **C11 Amihud 非流动性**：`ts_mean(abs(close / delay(close, 1) - 1) / (close * volume), 20)`，经济意义：非流动性股票交易成本高，投资者要求非流动性溢价，其预期收益更高。
- **C12 低换手**：`neg(ts_mean(volume * close / mktcap, 60))`，经济意义：低换手股票流动性差且受关注度低，投资者要求流动性补偿。
- **C47 成交额水平**：`neg(log(ts_mean(delay(close * volume, 42), 21)))`，滞后 2 个月的月均成交额取对数取负，经济意义：成交额高表明流动性好、预期收益低，流动性差的股票享有流动性溢价。
- **C48 换手率门槛**：`gt(ts_mean(volume / (mktcap / close), 63), 0.1)`，近 3 个月换手率均值高于 10% 记 1、低于 5% 记 0、中间记缺失，经济意义：换手率是流动性的反向代理，低换手股票流动性差，预期收益更高以补偿成本。
- **C49 量市值比**：`neg(ts_sum(volume / (mktcap / close), 252))`，过去 12 个月换手率之和取负，经济意义：年换手总量度量流动性，低换手股票受冷落，预期收益含流动性补偿。
- **C50 成交量趋势**：`ts_slope(月成交量, 60) / ts_mean(月成交量, 60)`，月成交量对时间趋势回归的斜率按均量缩放（月频，程序自算），经济意义：成交量持续上升反映关注度累积与情绪升温，其后收益偏低。
- **C51 成交量波动**：`neg(过去 36 个月月成交量的标准差)`（月频，程序自算），经济意义：成交量波动度量流动性不确定性，波动大者其后收益偏低。
- **C52 换手率波动**：`neg(过去 36 个月换手率的标准差)`（月频，程序自算），经济意义：换手率波动度量流动性不确定性，波动大者其后收益偏低。
- **C53 换手率变异系数**：`neg(过去 36 个月换手率标准差 / 均值)`（月频，程序自算），经济意义：换手率变异系数度量流动性稳定性，稳定性差者其后收益偏低。
- **C54 买卖价差（高低价估计）**：`2 * (exp(α) - 1) / (1 + exp(α))`，其中 α 由连续两日高低价比的函数 β、γ 按 Corwin-Schultz 法合成（程序实现），经济意义：买卖价差是交易成本的直接度量，价差大的股票须以更高收益补偿持有成本。
- **C55 零成交天数·1 月**：`ts_sum(where(gt(volume, 0), 0, 1), 21)`，近 1 个月零成交量天数，经济意义：零成交天数度量交易不连续性，流动性越差的股票预期收益越高。
- **C56 零成交天数·6 月**：`ts_mean(where(gt(volume, 0), 0, 1), 126)`，近 6 个月零成交天数均值，经济意义：零成交天数度量交易不连续性，流动性越差的股票预期收益越高。
- **C57 零成交天数·12 月**：`ts_mean(where(gt(volume, 0), 0, 1), 252)`，近 12 个月零成交天数均值，经济意义：零成交天数度量交易不连续性，流动性越差的股票预期收益越高。
- **C90 WQ#30 涨跌符号和×量比**：`(1 - rank(sign(close - delay(close, 1)) + sign(delay(close, 1) - delay(close, 2)) + sign(delay(close, 2) - delay(close, 3)))) * ts_sum(volume, 5) / ts_sum(volume, 20)`，经济意义：连续下跌叠加放量反映恐慌抛售，超卖后流动性需求者获得反转补偿。
- **C94 WQ#35 量秩×区间秩×收益秩**：`ts_rank(volume, 32) * (1 - ts_rank(close + high - low, 16)) * (1 - ts_rank(returns, 32))`，经济意义：放量且价格、收益居低位，刻画超卖状态，预期反转与流动性补偿。
- **C167 量均线比 VMA**：`ts_mean(volume, 20) / volume`，均量相对当日量，经济意义：均量相对当日量度量量能萎缩，交易清淡对应流动性下降与溢价上升。
- **C168 量离散 VSTD**：`ts_std(volume, 20) / volume`，成交量标准差按当日量归一，经济意义：成交量离散度量流动性不稳定性，量能波动越大流动性风险越高。
- **C170 放量占比 VSUMP**：`ts_sum(max(delta(volume, 1), 0), 20) / ts_sum(abs(delta(volume, 1)), 20)`，量增部分占量总变动之比，经济意义：量增占比度量买方需求强度，资金持续流入预示后续收益延续。
- **C171 缩量占比 VSUMN**：`ts_sum(max(-delta(volume, 1), 0), 20) / ts_sum(abs(delta(volume, 1)), 20)`，量减部分占量总变动之比，经济意义：量减占比度量交易需求退潮，资金流出压力下后续收益偏弱。
- **C172 净量变占比 VSUMD**：`(ts_sum(max(delta(volume, 1), 0), 20) - ts_sum(max(-delta(volume, 1), 0), 20)) / ts_sum(abs(delta(volume, 1)), 20)`，量增与量减之差占量总变动之比，经济意义：净量变占比度量资金流方向，净流入反映需求占优与动量延续。
- **C178 能量潮斜率 OBV**：`(OBV - delay(OBV, 20)) / ts_sum(volume, 20)`，其中 OBV = ts_cumsum(sign(delta(close, 1)) * volume) 为涨日加量、跌日减量的累积量（OBV 为程序自算），经济意义：累积量能斜率度量资金流趋势，量能持续累积反映买方力量占优。
- **C184 蔡金资金流**：`ts_sum(((close - low) - (high - close)) / (high - low) * volume, 20) / ts_sum(volume, 20)`，收盘位置加权的量占比，经济意义：以收盘位置加权成交量度量资金流向，收高放量反映买压占优。
- **C186 强力指数**：`(close - delay(close, 1)) * volume` 的 13 日指数平滑（程序自算），经济意义：价量乘积度量买卖力量强度，价涨量增反映多方力量与趋势延续。
