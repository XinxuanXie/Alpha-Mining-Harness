# 六、规模与价格水平

市值与名义价格的截面效应。构造以 log 市值与 log 价格为主；价格水平条目受本库调整价口径限制，见条目注记。

- **C15 规模**：`neg(log(mktcap))`，经济意义：小市值溢价，补偿流动性风险与信息不确定性。
- **C58 价格水平**：`neg(log(close))`。数据口径注：本库 close 为拆股调整后价格，名义价格不可得，此条在当前数据下不可用，经济意义：低价股多属困境公司，名义价格是风险与相对交易成本的代理。
- **C59 上市时长**：`neg(个股在面板中首次出现以来的月数)`，月数为程序自算量，经济意义：上市时间短意味着信息不确定性与估计风险高，要求更高风险补偿。
